## Disclosure boundary

Published content is restricted to:

- Problem statement
- Product intent
- Capability themes
- Non-sensitive technology direction
- Business value
- Portfolio positioning

Excluded content:

- Core code
- Internal diagrams
- Proprietary workflow logic
- Data models
- Security implementation details
- API contracts
- Credentials or deployment identifiers
- Business-confidential assumptions
